### 新增功能
- `LoginType` 枚举 + CuratorAccount 扩展 4 字段（loginType/wechatOpenId/phoneMasked/thirdPartyAvatarEmoji），JSON 向后兼容
- `WeChatAuthManager`：沙盒/正式双轨；AppID 走 gradle.properties `WECHAT_APP_ID` → BuildConfig（buildConfig=true 已开启）；OpenSDK 用反射调用，不引依赖
- `wxapi.WXEntryActivity`：SDK 强制回调位置；沙盒模式作为模拟授权页（微信绿风格）
- `PhoneAuthManager`：6 位码生成 / 60s 冷却 / 5min 有效期 / 脱敏；`dispatchSms()` 是短信平台接入点
- `OtpInputView`：6 方格 + 1dp 隐藏 EditText 承载键盘（退格/粘贴/输入法全兼容）；错误态用 flashError() 闪红 900ms
- `PhoneAuthActivity`：完整速登页（倒计时用 CountDownTimer，onDestroy 取消；restoreCooldownIfNeeded 防旋转绕过冷却）
- 认证页快捷登录区 + 通行证脱敏绑定徽章；HapticFeedbackEngine 没有 tick()，用 lightClick()

### 模拟器验证结论（uiautomator dump）
- 微信链路：授权页 → 允许 → 通行证「💬 微信 oWX_****xxxx」✓
- 手机号链路：13812348848 → 倒计时 55s → 沙盒明文验证码 → 输入自动校验 → 「📱 138****8848」✓
- 踩坑：
  1. install -r 后旧进程任务栈残留，点击新 Activity 无反应 → 先 `am force-stop` 再测
  2. `exported=false` 的 Activity 无法 adb am start（SecurityException），只能应用内点击
