## 🏛️ v1.0.0 核心全景能力矩阵

### 1. 📚 五大精神媒介深度统一体系 (Full-Media Lifecycle)
- **涵盖五大独立文化载体**：📖 书籍、🌸 番剧、🎬 影视、🎮 游戏、💿 音乐；
- **全链路动态自适应**：
  - 创作者标签（作者/译者、监督/声优、导演/主演、制作人/开发商、歌手/厂牌）；
  - 进度度量（页码/章节、话数/季度、季集/时长、游玩进度/成就、曲目/专辑）；
  - 状态分类（想读/在读/已读、想追/追番中/补完、想看/在看/已看、想玩/在玩/通关、想听/在听/听完）；
  - 时光漫忆与那年今日文案自动情境化适配。

### 2. 🏛️ 美术馆 Bento Grid 策展大厅 (Hub)
- 昼夜节律四时环境光（晨曦薄雾青金、晴午透白翡绿、暮霞落日暮紫、极夜曜石星蓝）；
- 极光流体着色器背景与 3.5% 高频 35mm 胶片微质感；
- 策展焦点大卡与双副卡，各媒介状态胶卷与快速进入。

### 3. 🍱 精神藏库一体化极简筛选系统 (Library)
- 消除双卡片断层割裂，整合为单一高质感毛玻璃面板；
- 清晰三级视觉层级：一级媒介胶囊流 ➔ 二级 iOS 风格状态分段器（Segmented Control） ➔ 三级轻量细描边标签（Outline Chips）；
- 消除冗余实心“全部”按钮堆叠，首屏垂直空间节省 40%，直接展示作品卡片。

### 4. 💽 先锋四大沉浸体验系统 (P1 ~ P4)
- **💽 P1: 3D 拟真黑胶唱机与复古磁带卡座**（铝合金双极各向异性光泽、金属唱臂物理落针、高透亚克力卡座自旋齿轮与羊皮纸歌词）；
- **🎧 P2: 物理线性马达触觉引擎与双耳空间音频**（盖印打击震感、撕票顿挫齿轮感、纸张摩擦感与 0MB 内存程序化 PCM 实时双耳空间声学渲染）；
- **🌌 P3: 3D 透视时空穿梭虫洞与心智流光胶囊**（三维透视投影、5 色光速拉丝粒子束、1x~10x 光速折跃与全息裂变展开）；
- **🗺️ P4: 3D 情绪等高线拓扑与精神海拔地形图**（复合高斯势能算法、26x26 精神海拔地貌、0m~8848m 等高剖面切片推杆与 1080P 超清海报生成）。

### 5. 🎟️ 纪念创享工坊 (Memoir)
- **🛂 精神巡礼护照盖章簿**（深蓝烫金封面 + 朱砂倾斜入境/通关印章 + 彩屑粒子礼花）；
- **🎟️ 复古电影透光撕票票根**（16:9 双联撕票打孔 + 4 种影院主题 + 3D 锯齿撕裂动效）；
- **🕹️ 游戏白金全息实体卡带**（3:4 白金卡带盒 + 4 种典藏材质）；
- **🌌 1:1 双生精神微卡**（跨媒介双星六维心智雷达同屏对照与金句合璧）。

### 6. 📱 纯本地数据掌控与 Glance 桌面视窗
- SQLite 纯本地安全持久化，零网络数据泄露风险；
- 支持全量 JSON 备份与 Obsidian Markdown / CSV 导出；
- 原生 Android 系统桌面小组件（每日金句便签、阅读专注打卡、在读进度卡片）。
