# 阅痕 ReadTrace v1.0.11 — 预置评分差异化与全景画卷调整发布说明 🎚️📜

[![Platform](https://img.shields.io/badge/Platform-Android%2012%2B-3DDC84?logo=android&logoColor=white)](https://developer.android.com)
[![Version](https://img.shields.io/badge/Version-v1.0.11-3A6348.svg)](https://github.com/liuGuanYi-hub/ReadTrace/releases)

> **版本定位**：按用户反馈取消预置作品「统一 8.0 分」机制，全新安装恢复按作品差异化的初始评分；同时收录全景画卷的五分类调整与顶部间距优化。

---

## 🎚️ 1. 取消「统一 8.0」· 预置评分回归差异化

- **背景**：自 v0.x 起，首次播种会执行 `UPDATE books SET rating = 8.0`，把全部预置作品（含富内容骨架书）的个人评分压成同一个 8.0；v9 迁移中还存在一处历史统一改写。
- **新逻辑**（仅对全新安装生效，老库永不改写）：
  - 有六维心智档案的作品：初始评分 = **六维均值**（含难度），与全息雷达自洽，约 7.4~9.7；
  - 无档案的硬编码种子：原 5 分制评分（4.5~5.0）线性散射回 **7.0~8.0**；
  - 富内容骨架书（种子源未含评分）：在 **7.0~8.0** 内逐部散布，整架不再同分。
- **实测**：全新安装 220 部作品形成 25 个评分档、零空值、无同分堆积；老库升级安装评分分布逐位不变。

## 📜 2. 全景画卷调整（v1.0.10 后用户反馈）

- 移除「全部全景」，仅保留书籍/番剧/影视/游戏/音乐五个单独分类，未指定媒介时默认书籍，「动漫长卷」入口改定向番剧；
- 顶部标题区与筛选行整体下移，悬浮返回键不再与「书籍」chip 挤压。

## 📦 3. 升级说明

- versionCode 46 → 47，versionName 1.0.10 → 1.0.11；
- **已装 v1.0.10 的设备**：直接覆盖安装不会改动现有数据（含统一 8.0 的旧预置评分）——如需差异化评分，请在「备份与数据管理 → 清空账号数据」后重新进入应用重新播种，或手动修改评分。
