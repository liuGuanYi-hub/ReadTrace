## 3. 产品方向

阅痕 ReadTrace v1.0 是安卓本地书籍记录 App。

产品气质：

- 安静
- 清晰
- 适合长期记录
- 以书籍内容和个人感受为中心

v1.0 不做：

- 登录
- 云同步
- AI
- 摘录和笔记
- 后端服务依赖

## 6. 数据规则

### 6.1 软删除

不允许物理删除用户数据。

书籍归档时：

- `is_deleted` 改为 `1`
- `deleted_at` 写入当前完整 ISO 时间
- 不删除数据库记录
- 默认列表只显示 `is_deleted = 0` 的书籍

未来可以增加：

- 回收站
- 恢复书籍
- 手动确认后的彻底删除

### 6.2 标签

`tags` 在本地数据库中使用 JSON 字符串保存。

示例：

```json
["青春", "日本文学", "短篇"]
```

应用层读取后转换为字符串列表使用。

### 6.3 评分

`rating` 可以为空。

如果填写：

- 范围必须是 1-10
- 允许一位小数，例如 8.5
- 不允许小于 1
- 不允许大于 10

### 6.4 时间格式

完整时间字段使用 ISO 8601：

- `created_at`
- `updated_at`
- `deleted_at`

示例：

```txt
2026-06-03T23:02:00+08:00
```

阅读日期只保存日期：

- `start_date`
- `finish_date`

示例：

```txt
2026-06-03
```

## 7. 建议数据表

第一版使用一张 `books` 表，数据库名为 `readtrace.db`，版本为 `1`。

```sql
CREATE TABLE books (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    author TEXT,
    cover_url TEXT,
    category TEXT,
    status TEXT NOT NULL DEFAULT 'wishlist',
    rating REAL,
    tags TEXT,
    short_comment TEXT,
    review TEXT,
    start_date TEXT,
    finish_date TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    is_deleted INTEGER NOT NULL DEFAULT 0,
    deleted_at TEXT
);
```

当前数据层位置：

```txt
app/src/main/java/com/example/readtrace/data/BookDatabaseHelper.kt
```

当前接口：

```kotlin
BookDatabaseHelper.insertBook(book): Long
BookDatabaseHelper.getBooks(status: BookStatus? = null): List<Book>
```

实现约束：

- 查询始终包含 `is_deleted = 0`
- 不提供物理删除方法
- 标签通过 Android 内置 `JSONArray` 转换
- 创建和更新时间由数据层写入 ISO 8601 字符串

## 8. 当前页面实现

### 8.1 书架首页

当前首页已经支持：

- 从 SQLite 读取书籍
- 返回首页时自动刷新
- 动态显示玻璃书籍卡片
- 全部、想读、在读、已读筛选
- 无记录时显示空书架状态

暂停和弃读记录会显示在“全部”中。

### 8.2 添加书籍页

当前添加页已经支持：

- 录入全部 v1.0 书籍字段
- 书名必填
- 评分限制为 1-10，最多一位小数
- 标签按中英文逗号拆分、去空和去重
- 日期通过 `DatePickerDialog` 选择
- 完成日期不得早于开始日期
- 保存成功后返回首页并立即刷新
