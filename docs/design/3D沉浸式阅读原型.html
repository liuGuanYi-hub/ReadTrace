让摘录不止是被存储，而是被「翻开」。移动鼠标环视书架，点击书籍抽出；在下方翻书页中阅读你摘录的章节与文段。纯 CSS 3D 实现，无外部依赖。

3D 书架 · 藏书即风景

书脊朝外的立体书架，鼠标移动时整个场景轻微转动（视差）。点击任意一本书，它会从架上抽出并前倾——这是「打开这本书的摘录」的入口。落地路径：v2.0 用 Compose Canvas / SceneView 实现真实光影，v1.x 可先用 2.5D 封面墙过渡。

翻书摘录 · 把文段翻出来

一本在透视中微微倾斜摊开的书。左页是摘录原文（衬线大字），右页是页码、章节、当日随想。点击右页或「下一页」翻页——就像回到抄下它的那个晚上。落地路径：v1.1 用 ViewPager2 + PageTransformer（rotateY 翻页动画）原生实现，成本低。
