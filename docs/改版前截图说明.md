## 对比时建议重点观察这几个位置

按「空灵 / 宁静 / 舒服」三个维度，改版前问题最集中的地方：

1. **主页顶部的极光渐变**（`01`）—— 粉紫橙大面积浓艳，与中间那张克制的白底卡片形成强烈反差
2. **藏库的四行筛选器**（`02`）—— 媒体类型 / 状态 / 评分区间 / 标签层层叠叠，进页面第一眼是筛选墙而非内容
3. **星系的彩色连线**（`03`）—— 五种颜色交织如蜘蛛网，节点标签还被截断
4. **纪念页的 5 张大卡片**（`04`）—— 每张都是「标题 + 三连句式描述 + 按钮 + 2 个装饰胶囊」，视觉重量极大
5. **详情页的 6 个操作按钮**（`06`）—— 其中「归档」是红色，在墨绿+金体系里像警报色
6. **社区页右下角的悬浮按钮**（`07`）—— 绿色大圆角块，略跳

## 另外值得记录的：配色底子其实是对的

```
readtrace_ink      #1A1C19   近黑
readtrace_muted    #686E64   灰绿
readtrace_accent   #3A6348   深墨绿
readtrace_gold     #9E7638   雅金
```

这套配色本身**完全撑得起"空灵宁静"**。改版的主要工作不是换色，而是**减掉堆在上层的东西**：
震动 147 处、动画 92 处、音效 24 处、弹窗（11 个 BottomSheet + 14 个 dialog 布局 + 25 个 Dialog 类）、
以及「共鸣 / 全息 / 灵魂 / 星系 / 破壁」这类宏大词共 51+ 处。
