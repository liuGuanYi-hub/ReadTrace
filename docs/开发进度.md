# 阅痕 ReadTrace 开发进度

## 当前阶段

当前阶段：v1.3「回收站与数据恢复机制」及「本地封面图片管线」开发完成，编译验证通过。

本阶段目标：

- 实现回收站（TrashActivity），支持分类查看已归档书籍与笔记、一键恢复与二次确认彻底删除
- 首页操作栏集成「🗑️ 回收站」入口
- 实现本地封面图片管线（CoverImageHelper），支持相册选图、防 OOM 采样、2:3 黄金比例中心裁剪与私有存储落盘
- 在添加/编辑页、首页书籍卡片与详情页全面接入本地封面渲染与更换/移除
- 彻底删除书籍或更换封面时自动清理旧本地图片文件
- 使用本地 Gradle assembleDebug 编译验证通过

## 当前工程事实

- Android 工程在仓库根目录
- 主模块是 `:app`
- project name 是 `readtrace`
- namespace 是 `com.example.readtrace`
- applicationId 是 `com.example.readtrace`
- 当前 UI 是 XML layout + AppCompat
- 当前首页是 iOS + Mac 玻璃冥想风动态书架页
- 当前入口是 `app/src/main/java/com/example/readtrace/MainActivity.kt`
- 当前 Gradle 配置使用 Android Gradle Plugin `9.1.1`
- 当前数据库是 `readtrace.db`，版本为 `2`（v1.1 起含 notes 表）

## 风险记录

- 不允许物理删除用户数据，所有删除默认必须走软删除。
- 任何可能减少 C 盘容量的操作，都必须先说明预计增加量并等待确认。
- v1.0 不做笔记和摘录，避免第一版范围变大。
- v1.0 不做登录、云同步和 AI。
- 本轮不运行 Gradle Sync、不构建、不下载依赖。

## 本轮验收标准

- 首次打开显示空书架
- 缺少书名时不能保存
- 非法评分和日期显示错误
- 保存后首页立即显示书籍卡片
- 重启 App 后书籍仍存在
- 全部、想读、在读、已读筛选结果正确
- 点击书籍卡片进入正确详情
- 编辑保存后详情页和首页立即更新
- 可空字段和日期可以清除
- 取消归档不改变记录
- 确认归档后记录从首页隐藏但数据库仍保留
- 首页概览统计与当前书架数据一致
- 书籍卡片长标题、长标签和简短评价不挤压布局
- 详情页首屏摘要与详细字段一致
- 数据层不存在物理删除 SQL
- 文档明确不物理删除用户数据
- 本轮未运行 Gradle Sync、未构建、未下载依赖
