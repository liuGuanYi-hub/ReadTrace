# 阅痕 ReadTrace 开发进度

## 当前阶段

当前阶段：v1.0.3「认证正式化：短信通道接入与微信降级完善」

> 版本号自 v1.0.0 起启用正式序列：**1.0.x 顺延，走到 1.0.30 后升 1.1**。

本阶段目标与里程碑成果：
- **阿里云短信正式通道**：`gradle.properties` 配置四项参数（AccessKey ID/Secret/签名/模板）后，手机号验证码自动切换为真实短信下发；未配置时维持沙盒明文回显，发送失败自动降级沙盒并提示；
- **零第三方依赖**：`AliyunSmsClient` 用 HttpURLConnection + 手写 HMAC-SHA1 签名直连 Dysmsapi，不引入任何 SDK；
- **微信正式模式完善**：明确双轨启用条件（AppID + OpenSDK aar），沙盒提示区分「未配置 AppID」与「已配置但未集成 SDK」；无服务端时拿到 code 后明确降级为本地互联档案并提示。
- 接入指南见 `docs/认证正式化接入指南.md`。

## 当前工程事实

- Android 工程在仓库根目录
- 主模块是 `:app`
- project name 是 `readtrace`
- namespace 是 `com.example.readtrace`
- applicationId 是 `com.example.readtrace`
- 当前 UI 是 XML layout + AppCompat
- 当前首页是 iOS + Mac 玻璃冥想风动态书架页
- 当前入口是 `app/src/main/java/com/example/readtrace/MainActivity.kt`
- 当前 Gradle 配置使用 Android Gradle Plugin `9.1.1`
- 当前数据库是 `readtrace.db`，版本为 `2`（v1.1 起含 notes 表）

## 本轮验收标准

- 首次打开显示空书架
- 缺少书名时不能保存
- 非法评分和日期显示错误
- 保存后首页立即显示书籍卡片
- 重启 App 后书籍仍存在
- 全部、想读、在读、已读筛选结果正确
- 点击书籍卡片进入正确详情
- 编辑保存后详情页和首页立即更新
- 可空字段和日期可以清除
- 取消归档不改变记录
- 确认归档后记录从首页隐藏但数据库仍保留
- 首页概览统计与当前书架数据一致
- 书籍卡片长标题、长标签和简短评价不挤压布局
- 详情页首屏摘要与详细字段一致
- 数据层不存在物理删除 SQL
- 文档明确不物理删除用户数据
- 本轮未运行 Gradle Sync、未构建、未下载依赖
