## 导入方式

1. **骨架数据**：应用内主页「📥」→ 选择对应分类预设，或「📂 选择本地 CSV 文件...」选中本目录任一 CSV；
2. **全量合入**：选「🌟 一键全量合入」一次性导入 205 部；
3. **富内容（含自动建库）**：随 APK assets 自动生效；也可在应用内主页「📥」→「🎨 选择本地富内容 JSON 文件...」
   选中本目录任一 `rich_content_*.json`——**一次导入即作品+富内容**：已存在的作品按标题合并补齐，
   缺失的作品按文件名推断媒介（anime→动漫 / books→书籍 / games→游戏 / movies_podcasts→影视 / music→音乐，
   非标准命名默认书籍）自动建最小骨架，创作者/评分等留空可后补。幂等，不覆盖已有内容。
