## 4. 产品目标

v1.0 只做安卓本地书籍记录核心功能：

- 添加书籍
- 查看书籍列表
- 查看书籍详情
- 编辑书籍
- 软删除 / 归档书籍
- 阅读状态
- 评分
- 标签
- 简短评价
- 读后感
- 本地保存数据

v1.0 不做登录、云同步、AI、摘录和笔记。

---

## 5. 数据原则

- 不允许物理删除用户数据。
- 删除默认使用软删除 / 归档。
- `tags` 使用 JSON 字符串保存。
- 评分可为空，填写时范围为 1-10，允许一位小数。
- `created_at` / `updated_at` / `deleted_at` 使用 ISO 8601。
- `start_date` / `finish_date` 使用 `YYYY-MM-DD`。
