# ReadTrace 内网封面服务

本目录存放全部 225 张预置作品封面（`covers/`，约 36.5 MB）。封面**不再打包进 APK**，
而是通过局域网 HTTP 服务加载：手机连接同一 Wi-Fi 后即可毫秒级加载，且 App 会自动
缓存到手机本地——**每张封面只需从内网下载一次，之后永久离线秒开**。

## 启动方法（在电脑上运行）

双击本目录下的 `启动封面服务器.bat`，或手动执行：

```bat
cd cover_server
python -m http.server 8000
```

看到 `Serving HTTP on 0.0.0.0 port 8000` 即启动成功，**保持窗口不要关闭**。

## 查看本机内网 IP

```bat
ipconfig
```

找「无线局域网适配器 WLAN」下的 `IPv4 地址`，例如 `192.168.1.100`。

## 在 App 中配置

打开 App → 我的 → 「内网封面服务」→ 填入：

```
http://192.168.1.100:8000
```

（把 IP 换成你电脑的实际内网 IP，端口保持 8000。）

## 常见问题

- **手机加载不出封面**：确认手机与电脑连的是同一个 Wi-Fi / 同一路由器；
  Windows 首次启动会弹防火墙授权，必须勾选「专用网络」允许访问。
- **电脑 IP 变了**：DHCP 可能更换 IP，重新 `ipconfig` 查看并在 App 中更新地址即可，
  已缓存到手机的封面不受影响（缓存按封面名记录，与 IP 无关）。
- **想让 IP 固定**：在路由器后台为电脑的 MAC 地址绑定静态 IP，或把本目录放到
  NAS / 软路由上长期运行。
- **离线使用**：从未加载过的封面需要连内网加载一次；已看过的封面都已缓存在
  手机 App 私有目录，离线直接显示。
